Software Specifications
=======================

These specifications describe the modules selected in the NeoCam integration
manifest. Each page identifies the source release and commit it describes. The
chapter order and table layout follow the AUTOSAR Classic Platform R22-11
software specification format. The technical adaptation and its scope are
described in :doc:`../architecture/architecture`.
