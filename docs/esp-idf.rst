ESP-IDF reference
=================

NeoCam's integration workflow builds firmware with ESP-IDF |esp-idf-version|
for |esp-idf-target|. The links below open Espressif's documentation for that
exact release and chip.

* `Programming Guide`_
* `Installation and first build`_
* `API Reference`_
* `ESP-IDF release notes`_

The documentation build reads ``idf-version`` and ``target`` from
``.github/workflows/integration.yml``. A change to that workflow on ``main``
rebuilds this page with the new links.

For NeoCam's project setup and build commands, see
:doc:`development/local-development`.
